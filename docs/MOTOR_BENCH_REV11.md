# REV 1.1 배선의 수동 모터 시험

문서 12쪽은 STOP/E-STOP/OL1 -> SAFE24 -> START/K0 -> RUN24 회로를 지정한다. 13쪽은 DI1/DI2 센서, DI3 KM2, DI4 예비다. RUN24를 별도 GPIO로 읽는 배선은 없다. 기본 배선의 수동 시험에 별도 permit GPIO를 필수로 요구했던 코드를 정정한다.

문서 28쪽 순서대로 제어회로와 현장 정지를 먼저 확인하고, US-52 최저속에서 현장 START 후 DO1을 시험한다. 앱은 /dev/gpiochip0, DI=[105,144,106], DO=[51,52], 별도 permit 미설정 조합을 지원한다. 설정되지 않은 출력 극성은 문서의 릴레이 배선과 Seeed J40 GPIO 명령을 기준으로 ON=1, OFF=0이다. 명시한 극성은 우선한다.

사용자 확정 동작: 모터와 LED를 켜기와 끄기 스위치로 조작한다. 일반 신호 변경 간격은 1초이며 시간 선택이나 시간제 자동 종료는 없다. DO1 전송 후 3초를 기다렸다가 DI3를 판정한다. DI3=0이면 접촉기 응답 확인으로 표시한다. 응답이 없거나 확인된 응답이 사라져도 경고만 표시하고 DO1 켜기 명령을 유지한다. 응답이 돌아오면 경고가 사라진다. 수동 끄기, 비상정지, 화면 연결 종료, I/O 오류는 출력을 OFF한다. 별도 운전 허가 입력을 구성한 경우 허가 상실도 즉시 OFF한다. DI3는 실제 벨트 회전을 검증하지 않는다.

이 기능은 RUN24를 소프트웨어로 관측했다고 주장하지 않는다. START 전에 요청하면 응답 대기 시간 내 DO1 요청이 잠시 존재할 수 있으므로 반드시 현장 START 이후 시험한다. OS 정지 시 물리 차단은 문서의 하드웨어 회로가 담당한다. 시험 중 실제 모터 속도 및 배선 건전성을 소프트웨어만으로 검증하지 않는다.

생산 운전 승인 조건은 변경하지 않는다. 기존 설정의 output_wiring_confirmed와 stop_circuit_confirmed를 자동으로 참으로 기록하지 않는다. 별도 permit GPIO를 구성한 설치는 기존 감시를 유지한다.

모터와 LED는 켜는 순서에 관계없이 동시에 시험할 수 있다. 각 출력의 상태와 1초 입력 제한을 따로 관리하고, 하나를 꺼도 다른 출력은 유지한다. 비상정지와 화면 연결 끊김, I/O 오류는 두 출력을 모두 끈다. 모터가 켜진 동안에는 카메라 설정 변경 등 별도 장비 점검 작업의 기존 차단 조건을 유지한다.

입출력 오류로 시험이 차단되면 장비 점검의 오류 해제를 누른다. 입력 연결이 정상이고 모터와 LED의 출력 명령이 OFF이며 DI3가 접촉기 꺼짐일 때 해제된다. 출력 신호를 보내거나 자동으로 재가동하지 않는다. 신호 변경 후 1초 대기는 유지된다. DI3 가동 미응답 경고만으로는 오류 해제를 요구하지 않는다. 오류 해제는 실제 배선이나 전원 문제를 해결했다는 뜻은 아니다.
