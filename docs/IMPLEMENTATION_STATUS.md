# 복구 및 검증 보고

2026년 9월 18일 기준이다. 사용자 원본 UI를 복구하고 추가 기능을 기존 화면에 연결했다. 소프트웨어 검토 후보이며 실제 장비 승인 상태는 NOT_VERIFIED다.

이후 요청한 목표 버튼과 코드별 색상 지정은 COLOR_BUTTONS.md를 따른다. 이 변경은 백엔드 65개와 프론트엔드 24개 시험을 통과했으며 인식 알고리즘을 변경하지 않았다.

## 현재 동작

원래 메인의 단순 계수와 조건 계수, 하단 메뉴, 조건 설정 3단계, 큰 수량 표시, 카메라와 검사 로그, 장비 점검, 작업 기록과 설정 구조를 사용한다. 작업 화면은 비밀번호 없이 진입한다. 환경 설정은 기존 비밀번호 하나로 열며 별도 계정 생성이나 역할 선택을 요구하지 않는다.

단순 계수와 조건 계수 모두 실제 서버 세션과 중복 방지 원장을 사용한다. 수동 보정, 오류 복구와 작업 종료는 감사 이력을 남긴다. STOP은 시작 요청 처리 중에도 별도로 보낼 수 있다. 전송 결과가 불확실하면 명령 처리 기록을 조회한다.

브랜드와 사용자 옵션 추가, 삭제, 기준표 가져오기와 내보내기, 이전 작업 불러오기, 개별 검사 사진과 판독 결과, 기록 페이지 추가 조회, 날짜별 감사 로그, 비밀번호 변경과 DB 백업을 유지했다. 통과 사진 저장 설정을 서버에 연결했다. 실패 사진은 계속 보존한다.

원본의 이동 중 계수 임계선은 정지 검사라는 사용자 결정과 맞지 않아 적용하지 않는다. 설정에는 현재 계수 방식과 이유를 i 도움말로 표시한다. 장비 점검도 가짜 성공 대신 실제 입력 신호, RFID 응답, 모델 로드를 확인한다. 실물 운전 차단 조건은 유지한다.

## 검증 결과

| 검사 | 결과 | 근거 |
|---|---|---|
| 기존 실제 사진 인식과 운영 기능 | 97개 통과 | verification/restoration-functional.xml |
| 프론트엔드 jsdom 동작 | 20개 통과 | verification/restoration-frontend.json |
| TypeScript와 Vite 빌드 | 통과 | 최종 빌드 로그 |
| 실제 HTTP와 WebSocket 연결 | 통과 | verification/restoration-http.json |
| 로컬 모델, 의존성과 실행 사전 검사 | 통과 | verification/restoration-preflight.json |
| 기존 로컬 서버 갱신과 비밀번호 보존 | 통과 | verification/restoration-live.json |
| 실물 운전과 정지 회로 | 미검증 | 조립 및 현장 인수 시험 필요 |
| 브라우저 직접 시각 검토 | 미실시 | 사용자 지시 대기 |

97개 기능 시험은 기존 PARSeq 실제 사진, 바코드 추출, 제공된 헤지스 규칙, 판정과 중복 계수, 저장 실패, STOP 우선 처리, 단절과 재시작, 백업 복원, 비밀번호 설정, 사진 보존 정책, 점검과 새 작업의 충돌, 날짜별 기록 조회를 포함한다. 실제 모델 시험은 네트워크와 torch.hub 다운로드 경로를 차단한 상태로 통과했다.

기존 400ms 속도 제한 시험 9개는 이번 기능 실행에서 제외했다. 이전 실행에서 423ms 또는 466ms로 실패한 기록이 있으며 성능 통과로 변경하지 않는다. 현장 목표 분당 처리량과 실측 기준도 미확정이다.

검증 루프의 수정 사항과 원본 기능별 연결 위치는 RESTORATION_CHECKLIST.md에 남겼다. 과거 verification 파일은 이전 빌드의 증거이며 현재 복구 버전은 restoration 접두사의 결과를 기준으로 한다.

## 남은 조건

제품 검출 라이브러리 이름과 경로, 물리 운전 허가 접점, 센서 역할과 극성, 정지 안정화 및 배출 시간, 조명과 초점, RFID 실제 명령 응답, J4012 BSP와 ARM64 환경은 실물 확인이 필요하다. 고정 옵션별 OCR 영역은 사용자 합의 없이 추가했던 경로이므로 최종 방식으로 확정하지 않았다. 기존 인쇄 번호 추출의 성공을 모든 목표 옵션 판독 성공으로 간주하지 않는다.

현장 1,000건 및 8시간 이상 시험과 가능 시 72시간 시험이 남아 있다. 실제 전원 복구, 프로세스 종료, OS 정지에서 모터가 꺼지는지 확인해야 한다. 소프트웨어 테스트만으로 산업 등급이나 물리적 안전을 승인하지 않는다.

## 배포

복구 버전은 release/txrx-0.3.0-restored-windows-offline.zip으로 별도 보관한다. 이전 ZIP을 덮어쓰지 않는다. 로컬 운영 DB와 비밀번호는 배포 ZIP에 포함하지 않는다. 원본 G: 프로젝트는 변경하지 않았다.
