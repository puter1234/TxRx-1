# Jetson에서 Git으로 업데이트하기

기존 장비 시험 설치를 마친 J4012 기준이다. 서버 터미널에서 Ctrl+C로 앱을 종료한 뒤 진행한다.

## 처음 한 번

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/puter1234/TxRx-1.git ~/TxRx-1-git
cd ~/TxRx-1-git
python3 scripts/use_existing_install.py ~/TxRx-1-bench
python3 scripts/run_bench.py
```

기존 설치 폴더 이름이 다르면 마지막에서 두 번째 명령의 경로를 바꾼다. 새 Git 폴더가 이미 존재하면 덮어쓰지 말고 해당 폴더가 이 저장소인지 확인한다.

연결 스크립트는 기존 Python 가상환경, 운영 DB, 모델과 패키지 폴더 및 로컬 기본 규칙 파일을 링크한다. 비밀번호, 카메라 설정과 작업 기록은 기존 DB를 그대로 사용한다. 실제 장치를 열거나 출력을 켜지 않는다. 기존 config/station.json은 runtime/station-local.json으로 한 번 복사하며, 이후 실행기는 이 로컬 설정을 우선 사용한다.

기존 `~/TxRx-1-bench` 폴더는 계속 사용하므로 삭제하거나 이름을 바꾸지 않는다. 두 폴더의 서버를 동시에 실행하지 않는다.

빌드된 화면은 Git에 포함한다. Jetson에 Node.js를 설치하거나 화면을 다시 빌드할 필요 없다. 모델, 가상환경, 작업 기록과 실제 기준 데이터는 Git에 올리지 않는다. 새 장비에는 이 자산과 의존성의 최초 설치가 별도로 필요하다.

## 이후 업데이트

서버 터미널에서 Ctrl+C로 종료한 다음 실행한다.

```bash
cd ~/TxRx-1-git
git pull --ff-only
python3 scripts/run_bench.py
```

pull이 실패하면 서버를 최신 상태로 업데이트했다고 간주하지 않는다. 오류를 확인하고 해결한 뒤 실행한다. Jetson에서 커밋할 필요는 없으므로 Git 사용자 이름과 이메일 설정은 필수가 아니다. 패키지 의존성이 바뀌는 업데이트는 별도 설치 안내를 따른다.

저장소가 비공개라 인증을 요구하면 GitHub 개인 액세스 토큰 또는 SSH 키 인증을 사용한다. 토큰을 명령어 URL에 넣거나 채팅으로 보내지 않는다.

## 이번 변경 검증 범위

짧은 모터 시험의 접촉기 응답 누락을 오류로 처리한다. 화면 숨김과 닫기 때 자동 정지는 해당 화면의 시험 요청 또는 실행이 있는 경우에만 보낸다. 명시적인 시험 전체 정지 버튼은 기존 동작을 유지한다. 실물 GPIO와 카메라 및 모터 검증은 현장 시험이 필요하다.
