# Jetson 운영 폴더

운영 폴더는 소문자 `~/txrx` 하나로 통일한다. 기존 두 폴더를 링크해 사용하는 방법은 폐기했다.

## 처음 한 번

기존 서버를 Ctrl+C로 종료한다. GitHub CLI로 비공개 저장소에 접근 가능한 계정의 로그인을 마친 상태에서 실행한다.

```bash
git clone https://github.com/puter1234/TxRx-1.git ~/txrx
cd ~/txrx
python3 scripts/use_existing_install.py
python3 scripts/run_bench.py
```

이관 스크립트가 기존 설치 폴더를 자동으로 찾는다. 기존 비밀번호, 카메라 설정과 기록이 들어 있는 운영 DB, 모델과 오프라인 패키지를 새 폴더로 복사한다. Python 가상환경은 새 위치에서 로컬 패키지로 다시 만든다. 기존 폴더를 참조하는 링크는 만들지 않는다.

기존 폴더가 다른 이름이면 `python3 scripts/use_existing_install.py /기존/폴더`로 지정한다. 서로 다른 운영 DB가 여러 개 발견되면 임의로 선택하지 않고 경로 지정을 요구한다. 대상 폴더에 기존 데이터가 있으면 덮어쓰지 않는다. 이관을 완료하고 패키지 설치 중 실패했다면 같은 명령을 다시 실행할 수 있다.

이관할 때는 기존 서버를 반드시 종료한다. 기존 폴더는 자동 삭제하지 않으며, 새 폴더에서 정상 동작을 확인할 때까지 백업으로 남겨 둔다. 새 설치가 완료되면 실행에 필요한 파일은 모두 `~/txrx` 안에 있다.

화면 빌드도 Git에 포함하므로 Jetson에서 Node.js 설치나 화면 빌드는 필요 없다. 모델, 가상환경과 실제 작업 데이터는 Git에서 제외된다. 다른 새 장비에는 최초 설치가 별도로 필요하다.

## 이후 업데이트

서버를 Ctrl+C로 종료하고 실행한다.

```bash
cd ~/txrx
git pull --ff-only
python3 scripts/install_bench.py
python3 scripts/run_bench.py
```

pull이 실패하면 먼저 오류를 해결한다. 의존성이 달라지는 업데이트는 별도 설치 안내를 따른다. 장비별 설정은 Git이 관리하지 않는 runtime/station-local.json에 보존한다.

OCR 시험을 사용할 때는 Pillow만으로 충분하지 않다. 초기 인터넷 연결 중에 `python3 scripts/install_ocr_jetson.py`를 실행한다. 이 명령은 같은 `.venv-bench`에 JetPack 6.1용 Torch, TorchVision, cuSPARSELt와 PARSeq 의존성을 설치하고 CUDA 및 실제 로컬 모델 로딩까지 확인한다. cuSPARSELt는 Python 패키지로 설치하므로 별도의 `libcusparselt` apt 설치 명령은 필요 없다. 다운로드한 Torch 휠은 `runtime/jetson-ai-wheels`에 보존한다. 운영 중에는 인터넷을 사용하지 않는다. `scripts/install_bench.py`만 다시 실행해도 이미 설치한 AI 패키지는 삭제되지 않는다.

## 비공개 저장소 인증

```bash
sudo apt install -y git gh
gh auth login
gh auth setup-git
```

GitHub.com, HTTPS, 브라우저 로그인을 선택하고 해당 저장소에 접근 가능한 계정으로 승인한다. 인증 토큰을 URL이나 채팅에 넣지 않는다. Jetson에서 코드를 받기만 하면 Git 사용자 이름과 이메일 설정은 필요 없다.
