# 목표 버튼과 색상 지정

2026년 9월 18일 사용자 요청에 따라 조건 설정의 목표값을 선택 목록에서 버튼으로 바꿨다. 색상, 사이즈, 품번과 추가 옵션 모두 하나씩 선택하며 선택 버튼에는 체크 표시와 테두리가 표시된다. 선택값이 많으면 검색할 수 있다.

환경 설정의 브랜드 관리에서 색상 옵션의 코드 버튼을 누르면 색을 지정한다. 기본 색상 팔레트 또는 직접 색상 선택을 사용하고 설정 저장을 누른다. 지정하지 않은 코드는 색을 추측하지 않는다. 사용자 정의 옵션에도 색상 버튼 사용을 켤 수 있다.

브랜드 옵션의 display 및 colors에 표시 설정을 저장한다. 색상 값은 #RRGGBB 형식만 허용하고 등록되지 않은 코드 매핑은 거부한다. 기존 기준표는 변경 없이 읽으며 가져오기와 내보내기에 색상 정보가 포함된다. 작업 시작 시 해당 버전을 고정한다.

표시 색상은 판정값이 아니다. N3 버튼의 배경색을 바꿔도 OCR과 RFID 대조에는 N3를 그대로 사용한다. 기존 인식 코드는 변경하지 않았다.

## 검증

백엔드 65개 테스트를 통과했다. 느린 실제 모델 회귀 1개는 이번 표시 변경에서 다시 실행하지 않았다. 새 검증은 색상 값 유효성, 저장 후 재조회와 가져오기, 진행 중 변경 차단, 색상 코드 판정 유지다. 프론트엔드 24개 테스트와 TypeScript 및 Vite 빌드가 통과했다.

프론트엔드 검증은 단일 선택, 지정 색상 반영, 미지정 색상 유지, 밝기에 따른 글자색, 키보드 조작, 많은 선택값 검색, 색상 설정 저장과 삭제된 코드 정리를 포함한다. 실제 HTTP와 WebSocket 통합 검사도 수행한다. 브라우저와 스크린샷을 이용한 검토는 하지 않는다.

결과 파일은 verification/color-station.xml, verification/color-frontend.json, verification/color-http.json과 verification/color-live.json이다. 8000번 서버에서 새 스키마와 정적 파일을 확인했으며 기존 설정 비밀번호는 사용자 확인 없이 초기화하지 않았다.

오프라인 배포물은 release/txrx-0.3.0-color-buttons-windows-offline.zip으로 별도 보관한다. 이번 작업 10회차 사용량은 잔여 69%였다.
