# RFID 시험

연결 설정의 입출력 및 RFID 설정에서 RFID 포트 찾기를 누른다. 직렬 포트를 선택한 뒤 RFID 설정 저장을 누른다. GPIO 입력 연결이나 LED를 끄지 않아도 RFID 설정을 저장할 수 있다. 읽기 중에는 포트를 변경할 수 없다. 카메라 검색의 성공 여부와 관계없이 직렬 포트를 검색한다. 검색 실패나 빈 목록은 화면에 표시한다.

같은 화면의 RFID 출력에서 송신 출력값을 변경한다. 기본값은 2600이며 2000은 20dBm, 2600은 26dBm이다. 소프트웨어 입력 범위는 0~2600이고 실제 장비가 받는 범위는 초기화 응답으로 확인한다. 저장한 출력은 RFID 시험과 생산 운전에 함께 사용하며 재시작 후에도 유지한다. 이미 연결된 생산 리더는 저장 시 출력 SET과 GET 일치를 확인한다. 장비가 값을 거부하거나 조회값이 다르면 저장 성공으로 처리하지 않는다. 읽기 중과 생산 작업 중에는 변경할 수 없다.

장비 점검의 태그 읽기를 누르면 결과와 오류가 RFID 카드에 표시된다. 모터와 LED를 켠 상태에서도 읽을 수 있고, 읽는 동안 출력 스위치도 조작할 수 있다. 동일 포트의 중복 읽기와 생산 작업 중 읽기는 차단한다. 기존 리더 명령 규격 확인 및 초기화 검증은 유지한다.

USB 장치 인식과 직렬 포트 생성은 별개다. 목록은 운영체제가 제공한 직렬 포트이며 USB 장치 목록 전체가 아니다. USB가 보이더라도 직렬 포트가 생성되지 않으면 해당 리더의 연결 방식과 드라이버를 확인해야 한다. 실제 장비 수신은 별도 현장 확인이 필요하다.

모터와 LED 켜기 버튼은 설정 차단 사유만으로 비활성화하지 않는다. 요청 시 서버가 검증하며, 거부 사유를 해당 스위치 아래에 표시한다. 이미 켜진 출력과 1초 연속 조작 제한, 요청 처리 중 중복 클릭은 계속 방지한다.
