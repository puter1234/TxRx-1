# 파이프라인 검토

검토일: 2026-10-21

## 발견한 문제와 수정

| 경로 | 문제 | 수정 후 동작 |
|---|---|---|
| 생산 작업 시작과 수동 재시작 | 모터만 켜고 DO4 고속 선택을 하지 않아 첫 DI1 전까지 저속으로 운전 | 고속을 선택한 뒤 모터 가동. 출력 설정 실패 시 모터와 속도 출력을 모두 해제 |
| DI1 이후 고속 복귀 | 저속 유지 시간이 센서 신호 확인 시간 이하이면 고속 복귀 직후 저속 명령을 다시 내려 저속에 머무름. 0ms에서도 발생 | 최초 DI1 신호에서 시작한 타이머만 속도를 제어. 센서 감지 확정 시 저속 명령을 반복하지 않음 |
| 생산 작업의 이동 중 촬영 | 촬영 예정 시각 이후에도 정지 촬영용 대기 경로에서 새 프레임 두 장을 추가로 기다림 | 예정 시각 이후 수신한 프레임을 바로 사용. 연속 촬영은 이전보다 큰 프레임 번호를 요구하고, 실제 지연 기록도 프레임 수신 시각을 사용 |

기존 코드에서 각 문제를 재현한 뒤 수정했다. 카메라 재연결은 제품의 중단된 저속 타이머를 이어가므로 일반 시작의 고속 선택과 별도로 처리한다. 이동 중 프레임 대기는 별도 스레드에서 실행하고 정지 요청, 카메라 단절, 시간 초과를 확인한다.

## 확인한 연결

1. DI1 입력 0에서 LED 점등과 저속 전환. 촬영과 RFID는 각각 저장된 지연을 사용한다.
2. 저속 유지 시간이 끝나면 고속 복귀. 촬영 완료 자체로 모터를 정지시키지 않는다.
3. DI2 입력 0에서 LED 소등. 생산 계수는 DI2와 검사 결과가 모두 완료된 제품에만 반영한다.
4. 카메라 사용 작업은 연결 단절 시 정지하고 설정 간격으로 재연결한다. 단순 계수는 카메라 단절에 의존하지 않는다. 수동 정지 이후에는 자동 재가동하지 않는다.
5. 모터 전원 정지 후 재가동에는 5초 제한을 적용한다. DO4 속도 전환은 모터 전원을 껐다 켜는 동작과 구분한다.
6. 기본 OCR 경로는 8000 x 6000 원본에서 만든 4000 x 3000 검출용 영상으로 택과 바코드 위치를 찾는다. 문자 좌표를 같은 48MP 원본으로 환산하고 원본에서 크롭한다. 0도와 180도 후보를 PARSeq에 전달한다.
7. 생산 판정은 읽은 문자열을 브랜드의 등록 옵션으로 해석한 뒤 작업 조건과 비교한다. 조건 불일치와 수량 불일치는 정지한다. 센서 OCR 시험에서는 문자 미검출을 결과에 남기고 다음 제품을 받는다.

## 검증 범위와 한계

자동 검증에는 실제 API, GPIO 제어 코드, SQLite와 모의 센서 및 카메라를 사용했다. 짧은 저속 유지 시간, 초기 고속 선택, 수동 재시작, 출력 실패, 프레임 시각과 중복, 정지 우선 처리, 재연결, 계수, 통계를 확인한다. 원본 픽셀 보존은 합성 48MP 영상으로 검사한다.

실행 결과는 280개 통과, 비공개 기준 데이터가 필요한 1개 건너뜀, 로컬 PARSeq와 현장 사진이 필요한 1개 제외다.

```bash
.venv/bin/python -m pytest tests_station tests/test_model_pipeline.py tests/test_stripe_locator.py tests/test_barcode_diagnostics.py -m 'not slow' -q
```

실제 ONNX 모델 두 개로 upstream 예시의 택 2개, 바코드 2개, 문자 영역 2개를 검출했다. 위치 검출과 문자 영역 추출은 이 클라우드 CPU에서 약 460~479ms였다. 이 예시는 원래 4000 x 3000 영상이며 연결 확인을 위해 8000 x 6000으로 확대했다. 실제 48MP 카메라 품질, Jetson 속도, PARSeq 판독률을 검증한 자료는 아니다.

이 환경에는 실제 장비와 로컬 PARSeq 모델 묶음 및 현장 표본이 없다. 따라서 촬영부터 실제 문자 판독까지의 성공률과 현장 처리량은 확인하지 못했다. 촬영 지연은 호스트 프레임 수신 시각을 기준으로 하므로 실제 노출 시각과의 차이 및 카메라 프레임 간격은 현장 측정이 필요하다.

다음 DI1이 선행하는 경우의 공정 정책은 기존 보류 사항이다. 현재는 오류로 정지하며 연속 제품 대기열로 처리하지 않는다.
