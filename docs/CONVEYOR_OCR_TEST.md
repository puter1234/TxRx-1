# 컨베이어에서 OCR 확인

장비 테스트의 기존 센서 연동 OCR 시험에서 실행한다. GPIO 번호나 서버 운전 모드를 입력할 필요가 없다. J4012 기본 배선의 DO4는 자동 적용한다.

1. 카메라 설정에서 **8000 x 6000, 48MP** 촬영 모드를 적용하고 초점과 노출을 맞춘다. 이 원본을 보관하고 같은 프레임의 4000 x 3000 축소본으로 위치를 찾는다. OCR용 글자는 48MP 원본에서 추출한다. OCR 시험의 `현재 영상 OCR 검사`로 정지된 제품의 글자가 읽히는지 확인할 수 있다.
2. `입력 연결`을 누른다. DI1과 DI2 앞을 비우고 두 입력이 1인지 확인한다.
3. `센서 시험`에서 `시험 방식`을 `컨베이어 연동`으로 선택한다.
   `바코드 위치 검출`의 기본값은 `택 검출과 바코드 분할`이다. 업데이트 후 기존 시험 설정도 한 번 새 모델로 전환하며 촬영 지연, 장수 등의 값은 유지한다. 이후 직접 선택한 비교 방식은 `설정 저장` 또는 시험 시작 시 저장한다.
4. 저속 유지 시간, 촬영 지연, 한 장 또는 여러 장, 촬영 간격을 지정한다. `설정 저장`으로 다음 실행에도 유지한다. 시험 시작 시에도 설정을 저장한다.
5. 수동 출력 시험이 켜져 있으면 `시험 비상정지`를 누른다. 모터를 끈 뒤에는 화면의 재시작 대기 5초가 끝나야 한다. 현장 START 후 `시험 시작`을 누른다. 서버는 OCR 모델을 먼저 불러오며 실패하면 출력을 켜지 않는다.
6. 제품을 하나 넣는다. DI1 입력 0에서 저속으로 전환하고 LED를 켠다. 촬영은 지정한 지연과 간격을 따르며, 저속 유지 시간이 끝나면 고속으로 돌아간다.
7. DI2 입력 0에서 LED를 끄고 통과 수를 한 번 올린다. DI1 해제는 통과 수를 올리지 않는다. OCR은 별도로 처리하며 사진, 읽은 문자, 문자 영역과 감지 후 촬영 시간을 같은 화면에 표시한다.
8. `시험 정지`로 종료한다. 결과와 사진은 화면에 남는다. `원본 크기`로 글자 윤곽을 확대 없이 확인하고 `원본 저장`으로 같은 사진을 내려받는다. 화면과 저장 모두 촬영한 크기의 PNG를 사용하며 글자 영역도 축소하거나 JPEG로 변환하지 않는다. 사진은 메모리에만 보관하며 생산 실적에는 합산하지 않는다.

OCR에서 문자를 읽지 못하거나 지정 형식과 맞지 않으면 사진과 판독 결과를 남기고 OCR 미검출 수를 올린다. 모터는 계속 운전하며 저속 유지 시간이 끝나면 고속으로 돌아간다. DI2에서 소등과 계수를 마친 뒤 다음 제품을 계속 시험할 수 있다. 한 장 촬영과 여러 장 촬영 모두 같은 방식으로 동작한다.

촬영 전에 DI2에 도착하면 소등하고 멈추며 이유를 표시한다. 촬영 지연이나 장수를 줄이거나 하드웨어의 저속을 조정한 뒤 다시 확인한다. DI1 없이 DI2가 들어오거나 이전 제품 통과 전에 다음 DI1이 들어오면 멈춘다. 새 촬영 프레임이 제한 시간 안에 들어오지 않거나 OCR 처리 자체에 오류가 발생해도 멈추고 이유를 표시한다.

카메라 연결 끊김, 화면 연결 끊김, 입출력 오류와 정지는 시험 출력을 끄고 남은 타이머를 취소한다. 재시작은 제품을 정리한 뒤 `시험 시작`으로 한다. 장비 조정용 시험은 자동 재가동하지 않는다.

기존 방식은 `센서 촬영`으로 선택한다. 선택한 센서의 해제에서 계수하고, 감지 뒤 들어오는 연속 프레임을 읽는 동작을 유지한다.

소프트웨어 검증은 가짜 센서, 카메라와 OCR 응답으로 수행한다. 실제 J4012의 릴레이 동작, 촬영 결과와 기존 PARSeq 모델의 인식률은 현장 확인 대상이다.

모터를 끄면 수동 켜기와 OCR 시험 재시작을 5초 동안 차단한다. 생산 운전의 카메라 자동 재연결과 정지 촬영 후 배출도 같은 간격을 지킨다. 정지 명령은 대기 없이 적용한다. DO4 고속과 저속 선택은 모터 전원 전환과 별개이므로 설정한 센서 타이밍을 유지한다.

`택 검출과 바코드 분할`은 저장소에 포함된 YOLO26n과 YOLO26n-seg ONNX 모델을 사용한다. 12MP 축소본에서 택 ROI와 바코드 마스크, 주변 문자 후보를 찾고 좌표를 48MP 원본으로 환산한다. 글자는 같은 48MP 프레임에서 다시 잘라 PARSeq에 전달하며 각 후보를 0도와 180도로 읽는다. OCR 시험은 바코드 값을 해독하지 않는다. 생산 작업의 OCR과 바코드 검사에도 같은 모델 경로를 사용하고 선택한 상품 조건과 대조한다. 설치와 검증 범위는 [48MP 모델 연결](BARCODE_PIPELINE_48MP.md)을 참고한다.

비교용 `줄무늬 검출 (G 채널)`은 바코드 값 판독을 실행하지 않는다. G 채널을 추출하고 긴 변 960픽셀의 검출용 영상에서 국소 평균과 분산으로 명암을 정규화한다. 방향이 일정한 반복 경계를 찾고 선 너비 변화와 세로 연속성을 확인한다. 후보가 없을 때만 최대 1600픽셀로 한 번 더 찾으며 원본 전체를 분할 검색하지 않는다. 후보 주변에서 경계를 보정하고 같은 원본 프레임의 위아래 글자를 기존 OCR에 전달한다. 전처리한 축소본은 OCR 입력으로 사용하지 않는다.

사진의 초록색 테두리는 바코드 위치 후보다. 그 아래에 촬영 원본과 탐색 크기, 모델별 처리 시간과 OCR 시간을 표시한다. 테두리는 화면에만 겹쳐 표시하며 원본 저장 파일에는 그리지 않는다. `OCR 시험`의 `현재 영상 OCR 검사`에서도 새 모델과 기존 두 검출 방식을 선택할 수 있다. 시험에서 고른 비교 방식은 생산 작업의 모델 설정을 바꾸지 않는다.

검증에는 해독할 값이 없는 줄무늬, 회전, 명암 차이, 흐림과 고해상도 합성 영상을 사용했다. 실제 라벨의 위치 검출률과 OCR 인식률, J4012 처리 시간은 시험 화면에서 확인한다. 기존 검출보다 항상 빠르다는 보장은 없으므로 같은 촬영 조건에서 두 방식의 위치와 시간을 비교한다.
