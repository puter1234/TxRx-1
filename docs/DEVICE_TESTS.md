# 장비 개별 시험

Git 배포 후속 변경: 짧은 모터 시험의 접촉기 응답 누락과 소유한 시험이 없는 화면의 자동 정지 요청을 수정했다. 관련 백엔드 시험은 12개 통과했다. Git 설치와 업데이트는 [J4012_GIT.md](J4012_GIT.md)를 따른다. 아래 11개 시험 결과는 최초 구현 당시 기록이다.

2026년 9월 18일 구현. J4012 실물 검증은 아직 하지 않았다.

## 사용 순서

1. 환경 설정 비밀번호로 들어가 장비 연결 탭을 연다.
2. 카메라의 장치 찾기를 누르고 연결된 USB 카메라를 선택한다.
3. 설정 읽기로 지원 해상도와 촬영 속도, 노출 및 초점 제어 목록을 가져온다.
4. 시험 적용으로 실제 영상을 확인하고 적용하고 저장을 누른다. 저장은 실제 적용값을 재조회하고 영상 연결까지 성공한 경우에만 이루어진다.
5. 입출력 연결에서 실제 배선의 ON 값, 운전 허가 GPIO와 입력값, 접촉기 응답 시간 및 센서 감지값을 지정한다. 배선과 정지 회로 확인 항목은 실제 확인 후 저장한다.
6. 장비 점검에서 입력 연결을 누른다. 출력 설정이 없어도 센서 원시값과 변화 횟수를 볼 수 있다.
7. 모터 시험 가동 또는 LED 켜기를 누른다. 모터는 최대 5초, LED는 최대 60초이며 선택한 시간이 지나면 끈다. 시험 전체 정지는 카메라 설정 중에도 사용할 수 있다.
8. 카메라 사진 촬영은 원본 해상도로 저장한다. 시험 사진은 생산 수량에 반영하지 않는다.
9. RFID 포트와 명령 규격 확인을 저장한 뒤 태그 읽기를 누르면 EPC와 읽은 횟수 및 RSSI가 나온다.
10. 입력 연결 종료로 GPIO 시험 소유권을 반환한다. 입력 연결 중에는 생산 작업을 새로 시작할 수 없다.

카메라 설정 화면에서도 LED를 켜고 초점과 노출을 조절할 수 있다. 출력 시험 화면을 벗어나거나 숨기면 정지를 요청하며, 화면 유지 신호가 1.5초 동안 없으면 서버에서 출력을 끈다. 별도의 현장 정지 회로는 계속 필요하다.

## OCR 촬영 시험

장비 점검의 OCR 촬영 시험에서 카메라 영상 위의 글자 영역을 드래그한다. 글자 방향과 밝기 증폭, 밝기 이동, 감마, 대비, 국소 대비 보정을 조절한 뒤 촬영하고 OCR 검사를 누른다. 서버는 새 프레임에서 해당 영역만 메모리로 잘라 기존 PARSeq 모델로 읽는다. 시험 사진은 디스크에 저장하지 않으며, 응답에는 실제 인식에 사용한 보정 영역과 문자값, 신뢰도가 들어 있다. 보정값 저장은 다음 작업부터 OCR 영역에 적용하며 바코드 영상에는 적용하지 않는다. 영역 좌표는 시험용이며 생산 작업의 메이커별 OCR 영역은 별도 설정을 유지한다. 완전히 검게 찍힌 글자는 소프트웨어 보정으로 복구할 수 없다.

## 실행 환경

USB 카메라의 실제 제어는 Linux의 v4l2-ctl과 OpenCV V4L2 백엔드를 사용한다. J4012에 v4l-utils, libgpiod 2.x, pyserial 및 기존 앱 의존성을 로컬 설치해야 한다. 운영 중 외부 서버나 인터넷을 호출하지 않는다. Windows에서는 설정 화면과 앱을 사용할 수 있지만 J4012 GPIO와 Linux UVC 제어를 실제 연결한 것으로 표시하지 않는다.

카메라 설정은 운영 DB의 usb_camera_profile에, 시험용 입출력 설정은 bench_setup에, OCR 보정값은 ocr_correction에 저장한다. 생산 운전 승인 체크값은 자동 변경하지 않는다. USB 카메라 설정은 HARDWARE 모드로 실행할 때도 동일한 카메라 관리자가 읽는다. 사용자가 사진 촬영을 누른 시험 사진만 runtime/device-tests에 저장한다.

모터 속도는 기존 US-52에서 조절한다. LED는 릴레이 ON/OFF이며 조광과 고속 스트로브를 구현했다고 간주하지 않는다. 입력값과 접촉기 피드백은 실제 회전 속도나 실제 점등 계측과 구분한다.

## 이번 소프트웨어 시험 결과

기존 백엔드 회귀 시험 65개 통과. 신규 tests_station/test_bench.py 11개 통과. 마지막 프론트엔드 TypeScript 검사와 Vite 빌드 통과.

신규 시험은 입력 연결과 출력 분리, 시간 만료 및 화면 단절 시 OFF, 지연된 ON 요청 차단, 중복 요청, 허가 상실, 접촉기 응답 이상, 설정 비밀번호와 핀 중복 검사, 카메라 설정 저장 및 복원, 사진 저장과 생산 기록 분리, 점검 중 생산 시작 차단, V4L2 목록 파싱을 포함한다.

가짜 장치 응답을 사용한 시험이며 실물 호환 인증이 아니다. 검증 중단 지시에 따라 마지막 수정 후 전체 재시험과 신규 프론트엔드 동작 시험은 실행하지 않았다. 브라우저를 열거나 화면을 시각 검토하지 않았다.

이동 중 촬영으로의 공정 변경은 요청대로 보류했다.
