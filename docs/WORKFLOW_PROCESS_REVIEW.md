# 실무 공정 재검토

검토일: 2026-10-16, Asia/Seoul

현재 구현을 `93de2f8`로 먼저 커밋하고 `origin/work`에 푸시한 뒤 작업 준비부터 종료와 통계 조회까지 다시 검토했다. 정상 운전뿐 아니라 정지 요청, 카메라 단절, 센서 재감지, 느린 저장이 겹치는 조건을 재현했다. 아래 문제는 후속 수정에 반영했다.

## 발견한 문제와 수정

| 상황 | 수정 전 문제 | 수정 후 동작 |
|---|---|---|
| 운전 시작 응답이 늦을 때 정지 | 정지 버튼도 비활성화됨 | 다른 명령 응답을 기다려도 정지를 전송할 수 있음 |
| 카메라 단절 후 촬영 취소 중 수동 정지 | 취소 대기 뒤 재연결 상태가 수동 정지를 덮어쓸 수 있음 | 재연결 상태를 먼저 기록하고 이후 정지가 자동 재가동을 취소함 |
| 카메라 단절 직후 관성으로 첫 제품이 DI1에 도착 | 대기 상태에서 검사 시작이 거부되어 감시 오류가 발생함 | 제품을 기록한 채 정지를 유지하고 실제 중단된 시간만큼 타이머를 조정함 |
| 카메라 복구 중 다음 DI1 선행 감지 | 발생한 오류를 확정하기 전에 재가동할 수 있음 | 제품 오류를 재연결보다 먼저 확정하고 정지함 |
| 사진 저장 중 DI2 추가 감지 | 추가 통과를 무시함 | 수량 불일치로 정지하고 늦은 저장 결과를 합격 수량에 더하지 않음 |
| 연결 함수가 끝났지만 영상이 수신되지 않음 | 재연결 성공으로 간주하여 다음 시도를 멈출 수 있음 | 실제 영상 연결 상태를 확인하고 설정 간격으로 다시 시도함 |
| 오류 해제와 제품 제거를 다른 순서로 실행 | READY로 바뀌어 남은 조치 버튼이 사라짐 | 제품이 남으면 PAUSED, 장비 오류가 남으면 FAULT를 유지하여 다음 조치를 완료할 수 있음 |
| 제품 제거 확인 | 새 공정에서도 과거 센서 극성 설정을 참조함 | 확정된 DI1과 DI2의 0 신호를 기준으로 가림 여부를 확인함 |
| 비전 계수 중 카메라 프레임 읽기 지연 | 카메라 잠금 대기가 센서 감시를 막음 | 프레임 읽기와 추론을 별도 실행 스레드에서 처리함 |
| 장비 시험 시작 기록이 느릴 때 정지 | 주기 감시가 시작 요청의 잠금을 기다리며 HTTP 처리를 막음 | 감시, 상태 전송, 유지관리, 장비 시험 예약의 잠금 대기를 HTTP 이벤트 루프 밖에서 처리함. 정지 이전에 대기하던 시험은 다시 실행해야 함 |
| 저장된 RFID 포트가 빠진 상태로 서버 시작 | RFID 초기화 실패가 GPIO 연결 전체를 종료함 | GPIO를 유지하고 RFID 오류를 따로 표시함. RFID 사용 작업은 준비 상태 검사에서 차단함 |
| 종료 시각이 없는 과거 작업 통계 | 오늘까지 계속 정지 중인 것으로 집계함 | 시간은 미기록으로 표시하고 시간 합계에서 제외함. 확인 가능한 종료 이벤트가 있으면 그 시각을 사용함 |
| 한 제품의 크기와 색상이 모두 불일치 | 작업별 불일치 2건, 일자별 1건으로 서로 다름 | 두 집계 모두 불일치 제품 1건으로 계산하고 개별 사유를 보존함 |

## 확인한 작업 흐름

1. 관리자 프리셋을 저장하고 작업자가 등록된 작업, 브랜드 옵션, 목표 수량을 선택한다. 프리셋 버전과 적용 설정은 시작한 작업에 고정된다.
2. DI1 감지 뒤 LED, 저속 유지, 촬영, RFID가 같은 제품과 기준 시각을 사용한다. DI2와 검사 결과가 모두 확인된 제품만 계수한다.
3. 검사 불일치, 예상하지 않은 DI2, 선행 DI1, 제한시간 초과는 정지한다. 느린 사진 저장 결과가 수동 정지 이후 수량을 올리지 않는다.
4. 카메라가 필요한 작업은 단절 시 정지하고 재연결한다. 수동 정지와 제품 오류가 없을 때만 자동 재가동한다. 센서 단순 계수는 카메라나 사용하지 않는 RFID 단절에 의존하지 않는다.
5. 오류 해제와 제품 제거 순서가 바뀌어도 남은 조치를 완료할 수 있다. 복구 버튼 자체가 모터를 가동하지 않는다.
6. 목표 수량 도달, 작업 종료, 서버 재시작과 늦은 검사 결과의 처리 경로를 회귀 시험으로 확인했다. 시험 작업은 생산 통계에서 기본 제외한다.
7. 한국 시간 자정 경계, 작업별 수량과 일자별 수량, CSV, 과거 기록의 누락 시각을 확인했다.

## 현장 확인과 보류

DO4의 실제 GPIO offset은 아직 지정되지 않았다. 해당 값과 기존 장비 운전 조건을 확인하기 전에는 실물 운전을 시작할 수 없다. 촬영 지연, 다중 촬영 간격, 센서 신호 유지 시간, 재연결 후 제품 위치와 실제 모델의 처리량은 장비에서 확인해야 한다.

사용자가 보류한 다음 DI1 선행 감지의 공정 정책과 와펜 이외 탐지 대상은 계속 보류한다. 현재 선행 DI1은 오류로 중단하며 연속 투입 대기열을 구현한 것으로 취급하지 않는다.
