# 브랜드 설정과 계수 시작

## 화면 위치

| 작업 | 위치 |
|---|---|
| RFID, OCR, 가격택, 폴리백 사용 선택 | 환경 설정 > 브랜드 관리 |
| 품번, 색상, 사이즈와 추가 옵션 | 브랜드의 상세 설정 > 상품 조건 |
| 저속 유지, 촬영 지연, 촬영 장수, RFID 지연 | 브랜드의 상세 설정 > 촬영과 센서 |
| 단순 계수의 속도와 센서 시간 | 환경 설정 > 계수 설정 > 단순 계수 |
| 와펜 계수 방법과 모델 파일 | 환경 설정 > 계수 설정 > 와펜 계수 |

기존 설정은 삭제하지 않는다. 한 기능에 여러 설정을 저장한 경우에는 저장된 설정 목록에서 선택한다. 설정 추가와 복사는 설정 관리 안에 있다. 설정 이름과 추가 버튼이 같은 목록에 나오는 구조를 없앴다.

상품 조건에서 품번, 색상, 사이즈 옆의 추가를 눌러 값을 한 개씩 등록한다. Enter로 연속 등록할 수 있다. 등록된 값을 누르면 수정과 삭제가 열린다. 색상은 해당 값의 편집 화면에서 지정한다. 중복된 값은 추가할 수 없으며, 코드를 수정해도 지정한 색상은 유지한다. 등록을 마치면 상단의 설정 저장을 누른다. 브랜드 이름과 항목 표시 방식은 추가 설정에서 변경한다. 기준표 가져오기와 양식 다운로드는 화면에서 제거했으며, 이미 저장된 판독 규칙과 데이터는 보존한다.

## 계수 시작

조건 계수는 브랜드 선택, 수량 설정, 상품 조건 선택 후 검사 시작을 누른다. 브랜드에 저장한 검사 항목을 기본으로 표시하고, 사용 가능한 검사 항목 안에서 선택할 수 있다. 저장된 촬영 설정이 하나면 자동으로 적용한다. 없으면 기본 실행 시간을 사용한다.

검사 시작은 작업 생성과 운전 시작을 함께 요청한다. 작업 생성 직후 센서 해제 확인을 기다려야 하는 경우에는 최대 1.5초 동안 준비 상태를 확인한다. 이때 정지를 누르면 시작 요청을 취소한다. 다른 장비 준비 조건이 충족되지 않으면 해당 사유를 표시하며 운전을 시작하지 않는다. 모터 정지 후 5초 제한은 유지한다.

단순 계수도 계수 시작을 한 번 누른다. 와펜 계수 방법은 관리자만 지정한다.

가격택과 폴리백 기준표는 각각 저장한다. 두 가지를 선택하면 각각의 등록된 바코드가 읽혀야 하며 상품 정보가 다르면 통과시키지 않는다.

## 확인 결과

2026-10-21 클라우드에서 확인했다.

- 서버와 영상 처리 자동 검사 276개 통과, 로컬 모델이 필요한 1개 제외.
- 화면 자동 검사 52개 통과, TypeScript 검사와 배포 빌드 통과.
- 브랜드 설정 저장 시 옵션, 색상, RFID 규칙과 바코드 기준표 보존 확인.
- 선택한 검사 항목과 저장된 촬영 시간이 작업에 반영되는지 확인.
- 시작 중 정지, 초기 센서 준비 대기, 모터 재시작 제한 관련 검사 통과.
- 브라우저에서 브랜드 목록, 촬영 설정, 두 계수 설정과 시작 3단계를 확인. 1280 x 800에서 가로 넘침 없음.
- 카메라 설정, OCR 테스트, 센서와 출력 조작, 이력, 수량 보정 관련 기존 화면 검사 통과.
- 클라우드 서버 재시작 전 SQLite 백업 후 브랜드와 설정 데이터가 동일한지 확인.

저장소에 없는 실물 사진과 PARSeq 묶음이 필요한 전체 이미지 검사는 실행하지 못했다. 실제 카메라, RFID, 컨베이어를 연결한 시연 결과는 포함하지 않는다.

## 반영

새 배포 파일을 저장소에 포함했다. 운영 컴퓨터에서 코드를 갱신한 뒤 기존 서버를 종료하고 사용하던 실행 명령으로 다시 실행한다. 브라우저는 Ctrl+F5로 갱신한다. 설정과 기록을 초기화할 필요는 없다.
